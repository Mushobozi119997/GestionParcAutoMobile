# 🚗 Gestion du Parc Automobile

Application de bureau Java pour la gestion complète d'un parc automobile.

## ✨ Fonctionnalités

- ✅ Gestion des véhicules (CRUD complet)
- ✅ Gestion des chauffeurs (CRUD complet)
- ✅ Gestion des missions (planification des trajets)
- ✅ Gestion des maintenances (suivi des réparations)
- ✅ Rapports et impressions (PDF, TXT)
- ✅ Recherche avancée par chauffeur ou véhicule
- ✅ Interface moderne Dark Mode
- ✅ Support de plusieurs devises (Euro, Dollar, Franc Congolais)

## 🛠️ Technologies utilisées

| Technologie | Version |
|-------------|---------|
| Java | 25 |
| Swing | - |
| MariaDB / MySQL | 10.4 |
| Maven | 3.13+ |
| FlatLaf | 3.4 |

## 📋 Prérequis

- XAMPP (Apache + MySQL/MariaDB)
- Java JDK 25+
- Maven (intégré dans NetBeans)
